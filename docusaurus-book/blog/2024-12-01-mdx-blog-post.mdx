## What is a ROS 2 Node?

A ROS 2 node is an independent process that performs a specific function in your robot system. Nodes communicate with each other through topics, services, and actions. Think of nodes as specialized workers in a factory—each has a specific job, and they coordinate through well-defined communication channels.

## Creating a Simple Robot Controller

Let's build a basic robot controller node that publishes velocity commands. This is the foundation for controlling any mobile robot:

```python
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist

class RobotController(Node):
    def __init__(self):
        super().__init__('robot_controller')
        # Create a publisher for velocity commands
        self.cmd_pub = self.create_publisher(
            Twist,           # Message type
            '/cmd_vel',      # Topic name
            10               # Queue size
        )
        # Create a timer to publish commands periodically
        self.timer = self.create_timer(0.5, self.timer_callback)
        self.get_logger().info('Robot Controller Node Started')

    def timer_callback(self):
        """Called every 0.5 seconds to publish velocity commands"""
        msg = Twist()
        msg.linear.x = 2.0   # Move forward at 2 m/s
        msg.angular.z = 0.5  # Rotate at 0.5 rad/s
        self.cmd_pub.publish(msg)
        self.get_logger().info(
            f'Publishing: Linear={msg.linear.x}, Angular={msg.angular.z}'
        )

def main(args=None):
    rclpy.init(args=args)
    controller = RobotController()
    
    try:
        rclpy.spin(controller)  # Keep the node running
    except KeyboardInterrupt:
        pass
    finally:
        controller.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Understanding the Code

Let's break down what's happening:

1. **Node Initialization**: `super().__init__('robot_controller')` creates a node named "robot_controller"
2. **Publisher**: `create_publisher()` creates a channel to send `Twist` messages on `/cmd_vel` topic
3. **Timer**: `create_timer()` sets up a periodic callback (every 0.5 seconds)
4. **Message Publishing**: `publish()` sends the velocity command

## Try It Yourself

You can test this code in Gazebo simulation. Here's how:

1. **Start Gazebo with a robot**:
```bash
ros2 launch gazebo_ros gazebo.launch.py
```

2. **Run your controller**:
```bash
python3 robot_controller.py
```

3. **Monitor the topic**:
```bash
ros2 topic echo /cmd_vel
```
